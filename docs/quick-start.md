# 快速开始

## 第一次使用

1. 把发布包解压到一个有写入权限的位置（不要放 `C:/Program Files`）。
2. 双击根目录的「采购下单系统」快捷方式。快捷方式丢了就双击 `start.bat`。
3. 浏览器会自动打开导入向导，选择你从易快报导出的合同文件夹，点「开始导入」。
4. 导入完成后自动进入系统；以后双击同一个快捷方式即可。

不需要安装 Python、Node，也不需要联网。所有数据都在本机 `data/` 目录。

## 日常使用

- 下单：选供应商 → 搜产品 → 填数量单价 → 选付款方式 → 生成产品订购清单。
- 签合同：顶部切到「合同」，选新签或续签，生成主合同或供应商信息收集表。
- 更新合同：顶部切到「导入」，粘贴易快报链接，先预览再导入；也可以直接选本地文件夹。
- 关闭系统：直接关掉浏览器页面，约 10 秒后服务自动退出；页面关不掉时双击 `stop.bat`。

## 发给同事

把整个 zip 发过去，让对方解压后双击快捷方式即可。不要在微信里直接发文件夹，
也不要只发 `start.bat`，程序、模板和运行时必须在一起。

## 出问题

- 双击没反应：双击 `start.bat` 看控制台报错，或运行 `maintenance.bat` 选「查看日志」。
- 页面打不开：先确认没有把文件夹放在只读位置；再试 `stop.bat` 后重新双击快捷方式。
- 快捷方式失效：运行 `maintenance.bat`，选「重建快捷方式」。
