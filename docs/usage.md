# 使用说明

## 下单

1. 选择供应商（支持模糊搜索）。供应商提示会按甲方分行，分别显示最近签约、合同期限和剩余天数。
2. 在产品搜索框输入名称、别名或规格，点结果加入清单。
3. 修改数量、单价、备注，合计与付款方式会实时重算。
4. 付款方式按合计金额限制：
   - 低于阈值：只能全款
   - 高于阈值：全款 / 30% 预付 / 50% 预付
5. 页面底部的「甲方（我方）」可修改公司名称、联系人、电话、邮箱和地址，改动会自动保存；导出的清单和主体合同会带上这些信息。
6. 点「生成产品订购清单」，浏览器下载 docx，图片已内嵌；购货单位、甲方签署行和主合同日期都跟随所选甲方。
7. 供应商面板会显示数据库更新时间和未导入的新合同数量，有需要时点「立即更新」即可在页面内完成导入。

换供应商按订单状态处理：空单直接切换；有产品但未导出时每次都会提示“会清空已选产品、单价和付款方式”，确定后清空并切换，取消则保留原供应商和已填内容；已导出成功后视为一单结束，直接清空并切换，不再弹窗。供应商搜索框只要输入了不同名称、删空后离开或点 ×，都会立即走同一套提示；预付款起订金额和甲方选择不会被清空。

## 合同倒计时

页面地址：`http://127.0.0.1:8899/#/expiry`（旧书签 `/expiry.html` 会自动跳转）。

- 顶部搜索框可按供应商、合同号或文件名查具体合同；多个关键词用空格分隔（同时满足）。
  搜索结果直接显示签署日期、合同期、到期日和文件，可点「续签」带入新增主合同页。
- 顶部四个数字：已过期、7 天内到期、30 天内到期、未登记 / 待确认。
- 同一供应商在两家甲方下都有合同时分两行显示，各自计算期限；没识别出甲方的合同进「未确认甲方」，可在页面筛出来逐条指定。
- 下面按剩余天数排序，已过期的按“刚过期”排前面。
- 可以按档位筛选：全部、紧急（30 天内）、未确认甲方、已过期、3 天内、1 周内……
- 每行两个操作：
  - 「续签」→ 带着供应商进入「新增主合同」页，档案信息自动带入。
  - 「修改期限 / 登记期限」→ 手工补录起始日、到期日。
- 显示「待确认」表示这份新合同没写期限，系统不会直接按旧合同判过期，
  会在下面标出「上一份」到期日，核实后再登记即可。

## 新增主合同

页面地址：`http://127.0.0.1:8899/#/contract`（旧书签 `/contract.html` 会自动跳转）。

- 第 1 步选：续签 / 到期重签（老供应商），或首次签约（新供应商）。
- 顶部选择批采、一件代发、单次简易版。
- 甲方信息来自后端目录，在系统状态页维护；续签会带上倒计时页选中的甲方。
- 乙方信息可以从历史供应商档案带入；填完可顺手保存档案。
- 生成主合同使用 `templates/` 下的法务模板，只替换占位内容，格式不变。
- 「供应商信息收集表」用于首次签约前发给对方填写。

## 导入

### 易快报

1. 在企业微信里打开易快报，复制带 `accessToken` 的链接。
2. 粘贴到导入页，点「预览」：只读取单据列表，不下载文件。
3. 确认新增/重复数量后点「开始导入」，页面显示下载与入库进度。
4. 完成后可查看批次报告；重复合同默认跳过。

链接会过期。提示「链接已过期」时，回到企业微信重新复制，不要反复重试。

### 本地文件夹

适合已经从易快报下载好、或别人发来的合同。选择文件夹后走同一套解析与去重流程。

支持 `.docx` 和 `.doc`。`.doc` 是 Word 97-2003 格式，系统只登记供应商、签署日期和合同期限，
不提取产品行；产品仍来自 `.docx` 合同。老合同没有写期限的，会显示「待确认」或「未登记」，
可以在合同倒计时页手工补录。

## 系统状态

显示版本、数据结构版本、数据目录、库大小、产品/供应商/图片数量、备份列表。
可以立即备份、下载备份、导出完整数据包（数据库 + 图片）。

下方还有两块维护功能：

- 「甲方信息」：维护两家签约主体的简称、信用代码、联系人、电话、邮箱、地址；
  下单页与新增主合同页都从这里读取。
- 「供应商去重」：列出“短名 / 全称”与错别字候选，逐条确认合并；合并前自动备份，
  合并记录写入日志。
