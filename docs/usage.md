# 使用说明

## 下单

1. 选择供应商（支持模糊搜索）。
2. 在产品搜索框输入名称、别名或规格，点结果加入清单。
3. 修改数量、单价、备注，合计与付款方式会实时重算。
4. 付款方式按合计金额限制：
   - 低于阈值：只能全款
   - 高于阈值：全款 / 30% 预付 / 50% 预付
5. 点「生成产品订购清单」，浏览器下载 docx，图片已内嵌。

## 合同

- 顶部选择「新签」或「续签」，以及批采、一件代发、单次简易版。
- 乙方信息可以从历史供应商档案带入；填完可顺手保存档案。
- 生成主合同使用 `templates/` 下的法务模板，只替换占位内容，格式不变。
- 「供应商信息收集表」用于首次签约前发给对方填写。
- 合同到期提醒显示在页面顶部，可手工登记或撤销期限。

## 导入

### 易快报

1. 在企业微信里打开易快报，复制带 `accessToken` 的链接。
2. 粘贴到导入页，点「预览」：只读取单据列表，不下载文件。
3. 确认新增/重复数量后点「开始导入」，页面显示下载与入库进度。
4. 完成后可查看批次报告；重复合同默认跳过。

链接会过期。提示「链接已过期」时，回到企业微信重新复制，不要反复重试。

### 本地文件夹

适合已经从易快报下载好、或别人发来的合同。选择文件夹后走同一套解析与去重流程。

## 系统状态

显示版本、数据结构版本、数据目录、库大小、产品/供应商/图片数量、备份列表。
可以立即备份、下载备份、导出完整数据包（数据库 + 图片）。
