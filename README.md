# PurchaseOrderSystem

本地运行的采购合同下单系统。从易快报导出的合同附件里解析产品与供应商，生成《产品订购清单》《购销框架合同》，并跟踪合同到期。

纯本地运行，不依赖服务器和数据库服务：Python 标准库 `http.server` + SQLite，前端是原生 HTML/JS，无构建步骤。

## 功能

- **合同解析入库**：扫描 `.docx` 合同，提取产品、规格、历史单价、供应商、签署日期、合同期限
- **下单**：按供应商 / 产品检索，自动计算金额与付款方式，导出《产品订购清单》
- **合同生成**：批采、一件代发、单次简易版三套模板，填充占位符并清理高亮
- **供应商档案**：从历史合同自动补全联系人、税号、对公账户，续签时自动带入
- **到期预警**：按 3 / 7 / 30 / 90 / 180 天分档，支持手工登记与续签
- **增量导入**：按 S 单号去重，只处理新增或变更的合同

## 目录结构

```
├─ 启动网页版.bat           启动本地服务并打开浏览器
├─ 关闭系统.bat             停止服务
├─ 扫描合同并更新数据库.bat  增量导入新合同
├─ 工具/
│  ├─ 打开系统_静默.py      HTTP 服务与接口
│  ├─ sqlite_store.py       SQLite 数据层（唯一数据源）
│  ├─ _工具_生成数据库.py    合同解析
│  ├─ 合并新合同.py          增量合并
│  ├─ 生成主合同.py          合同 / 信息表生成
│  ├─ 建立供应商档案.py      供应商信息补全
│  └─ 回填合同期限.py        合同期限回填
└─ web/
   ├─ index.html            下单页
   ├─ contract.html         主合同页
   └─ app.js                下单页逻辑
```

## 运行环境

- Windows 10 / 11
- Python 3.13（便携版放在 `运行环境/`）
- 依赖：`python-docx`、`openpyxl`

本仓库只包含源代码，**不含**运行环境、合同模板、产品图片与任何业务数据。

## 首次使用

1. 把便携 Python 解压到 `运行环境/`（含 `python.exe`、`pythonw.exe`）
2. 把合同模板放进 `合同模板/`
3. 运行 `工具/更新数据源.py`，粘贴合同文件夹路径，导入生成 `data/purchase.db`
4. 双击 `启动网页版.bat`

## 数据

`data/purchase.db` 是唯一正式数据源；`web/data.js` 只是由数据库生成的网页缓存，可随时重建。
两者都在 `.gitignore` 中排除，不会进入版本库。
