  电脑上【不用装任何软件】。整个文件夹解压后即可使用。

──────────────────────────────────────────────────────────
  第一次使用：只要 3 步
──────────────────────────────────────────────────────────

  第 1 步
    先从 WorkBuddy 接入企微易快报，导出【你自己的】合同附件文件夹（.docx）。
    （注意：不能用别人的合同数据）

  第 2 步
    双击「启动网页版.bat」。浏览器会自动打开；
    第一次会进入导入向导（不用装 Python，也不用改文件关联）。

        · 在向导里点「浏览…」选中合同文件夹，或直接粘贴路径；
        · 点「开始导入」，等进度走完，页面自动进入系统；
        · 以后双击「启动网页版.bat」就直接进系统；
        · 不用时双击「关闭系统.bat」即可关闭服务。

  第 3 步
    在网页上：选供应商 → 选产品 → 填单价数量 → 选付款方式
              → 点「导出订购清单」→ 用 Word 打开完成。

──────────────────────────────────────────────────────────
  要签「主合同」时用这个（新供应商首签 / 老供应商续签）
──────────────────────────────────────────────────────────

  在首页点右上角「＋ 主合同」，进入合同页（新签 / 续签都在这里）
    生成前会按合同类型校验模板黄色高亮字段（含订单总金额）。
    合同页可选全款 / 30%预付 / 50%预付；低于起订金额只能全款。

    续签：选「续签」→ 搜公司名 → 信息自动全填 → 生成 Word
          （老信息是从你历史合同里自动抓的，不用再问对方）

    新签：选「新签」→ 先点「导出信息收集表」发给对方填
          → 收回后贴进去 → 生成 Word（同时自动存入档案）

  ★ 出不了合同？多半是缺了 联系地址 / 对公账号 / 开户行 其中之一，
    页面会提示你。用「导出信息收集表」找对方要齐即可。

  想知道谁的资料还不全：双击「工具\供应商信息缺口表.py」，
  会生成《待补资料-供应商清单.xlsx》，按紧急程度排好了。

──────────────────────────────────────────────────────────
  日常使用（已经有数据了）
──────────────────────────────────────────────────────────

  双击「启动网页版.bat」即可，浏览器自动打开。

  想更方便：右键「启动网页版.bat」→ 发送到 → 桌面快捷方式。

  ★ 关掉网页约 10 秒后服务会自动退出；也可以用「关闭系统.bat」。

  有新合同了：
    点页面右上角「导入」→ 粘贴易快报链接 → 检查/预览 → 开始导入。
    也可以切到「本地文件夹」，直接导入已经下载好的合同文件夹。
    （旧的「扫描合同并更新数据库.bat」仍可用，会扫描本机常见目录）

──────────────────────────────────────────────────────────
  遇到问题？
──────────────────────────────────────────────────────────

  A. 双击 .py 没反应 / 被安全软件拦了
     → 试试双击「启动网页版.bat」
     → 或让 IT 把这个文件夹加入杀毒软件白名单

  B. 页面能打开，但数据明显不全（比如只剩几条）
     → 浏览器没加载最新数据，按 Ctrl + F5 强制刷新一次

  C. 其他问题
     → 双击「工具\诊断问题.bat」，会生成「诊断报告.txt」，
       把这个文件发给小简，就能立刻定位。

------------------------------------------------------------
【有新合同了，怎么更新数据？】
------------------------------------------------------------

双击「工具\合并新合同.py」：把新合同所在文件夹
路径粘贴进去 → 回车。等它跑完，产品库就自动更新了。

特点：
  · 只增不减 —— 原来有的产品、供应商、图片一张都不会少
  · 自动跳过已经收过的合同 —— 重复跑不会让下单次数翻倍
  · 跑之前会自动备份数据库（data\backups）

小提示：直接指向你整个「合同审批附件」大目录也行，
        它自己认得哪些是新的。


【为什么有时会打不开 / 打不开怎么办】

  1. 双击的要是「工具\打开系统.py」，不是「采购下单系统 - 兴趣岛.url」。
     .url 只是一个网址，服务没开着就必然连不上（ERR_CONNECTION_REFUSED）。

  2. 想开机自动启动：把「工具\开机自启_静默服务.pyw」的快捷方式
     放进 Windows 启动文件夹（Win+R 输入 shell:startup），
     以后开机服务就在后台跑，不会弹窗口。

  3. 如果是刚开机、服务还没起来：第一次启动大约 7 秒，
     浏览器会自动弹出来，请耐心等一下。
     这 7 秒里就算再双击几次也没关系 —— 已经做了防连点，不会跑出两个服务。

  4. 实在打不开：双击「启动网页版.bat」，或重启一次电脑。
